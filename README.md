# 🛍️ Retail Insight 360
### 📊 Retail Inventory & Stockout Analysis | SQL + Power BI

> Turning retail data into meaningful insights for sales performance, inventory monitoring, and smarter business decisions.

---

## 🌟 Project Overview

Retail Insight 360 is a data analytics portfolio project built using **SQL and Microsoft Power BI**. It explores sales performance, profitability, product trends, and inventory risks through an interactive dashboard.

## 🎯 Business Objectives

- 📈 Analyze sales and profit performance over time.
- 📦 Monitor inventory levels and stock availability.
- ⚠️ Identify products at or below their reorder thresholds.
- 🏆 Compare category performance and top-selling products.
- 🔎 Enable interactive analysis by region and category.

## 🧰 Tech Stack

| Technology | Purpose |
|---|---|
| 🗄️ SQL | Querying and analyzing retail data |
| 📊 Power BI | Interactive dashboard development |
| 🧮 DAX | KPI calculations and measures |
| 🔗 Data Modeling | Connecting sales, product, and inventory tables |

## 📊 Dashboard Highlights

- 💰 **Sales & Profit KPIs** — Monitor overall performance.
- 🛒 **Total Orders** — Track order volume.
- 📦 **Reorder Monitoring** — Find products needing replenishment.
- 📅 **Monthly Trends** — Explore sales and profit over time.
- 🏷️ **Category Analysis** — Compare sales across categories.
- 🏆 **Top 10 Products** — Identify leading products by sales.
- 🍩 **Inventory Status** — Review stock availability.
- 🎛️ **Interactive Filters** — Explore by region and category.
